**Français**
- Warmup : après l'arrivée, le run repart tout seul au bout de 5 secondes si vous n'appuyez pas sur Respawn / Restart (pas en spectateur). Un compte à rebours « RESPAWN IN 5 » s'affiche sous WARMUP.
- Launcher, page Maps : glisser-déposer des fichiers .cmap (ou d'un dossier de maps) depuis l'Explorateur directement dans la liste.
- Ordre de passage des maps : faites glisser les maps dans la liste, ou flèches ▲ / ▼.
- Case « Ordre aléatoire » : le serveur mélange les maps (chacune passe une fois avant qu'une map revienne, jamais deux fois de suite la même).
- Un serveur lancé prend en compte l'ordre et le mode aléatoire à la map suivante.

**English**
- Warmup: after the finish, the run restarts by itself after 5 seconds if you don't press Respawn / Restart (not while spectating). A "RESPAWN IN 5" countdown is shown below WARMUP.
- Launcher, Maps page: drag and drop .cmap files (or a folder of maps) from the Explorer directly into the list.
- Playing order of the maps: drag the maps in the list, or ▲ / ▼ arrows.
- "Random order" box: the server shuffles the maps (each one is played once before a map comes back, never the same one twice in a row).
- A running server uses the order and the random mode at the next map.
