**Français**
- Mise à jour obligatoire : au démarrage, si une nouvelle version existe, une fenêtre propose de l'installer ou de quitter ; le launcher n'est pas utilisable sans la mise à jour (tous les joueurs de la LAN ont la même version).
- Sans accès à Internet, le launcher s'ouvre normalement.

**English**
- Mandatory update: at start, if a new version exists, a window offers to install it or to quit; the launcher can't be used without the update (every player of the LAN has the same version).
- Without Internet access, the launcher opens normally.
